# วิธีใส่รูปโปรไฟล์จริง (ครอปจาก PDF เดิม)

1. เปิดไฟล์ CV PDF ต้นฉบับ
2. ครอปเฉพาะรูปถ่ายหน้าตรง (พื้นหลังสีฟ้า เสื้อขาว)
3. บันทึกเป็นไฟล์ชื่อ `profile.jpg` ไว้ในโฟลเดอร์นี้ (`assets/images/`)
   - ถ้าเป็น .png ให้ใช้ชื่อ `profile.png` ก็ได้ (แอปรองรับทั้ง 2 นามสกุล)
4. รัน `flutter pub get` แล้วกด Rebuild / Hot restart

ตอนนี้ถ้ายังไม่มีไฟล์ แอปจะโชว์ตัวอักษร "ก" แทนโดยไม่ error
และตอน Export PDF จะข้ามรูปไปก่อนอัตโนมัติ
